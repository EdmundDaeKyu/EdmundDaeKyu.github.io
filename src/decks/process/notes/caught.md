## 사례별 확인 방법과 결과 !wide
| 방법 | 확인 방법 | 결과 |
|---|---|---|
| 측정 | 함정 칸을 일렬로 이어 깔고 대시로 건너며 잃는 체력을 표로 정리했다 | 당시 대시 4.76m로 세 칸(6m)까지 피해가 0이었다. 맵에 지나갈 틈을 따로 남기지 않았다 |

| 자동 검사 | 모의 처리 대신 실제로 저장하고 불러왔다 | 옛 호환 코드가 1500코인어치 영구 해금을 무료로 주고 있었다. 저장 데이터에 표식을 넣어 막았다 |
| 재현 검사 | 고치기 전에 옛 코드에서 실패하는 검사부터 만들었다 | 다른 3D 월드의 캐릭터까지 같은 그룹으로 묶어 센 탓에, 설명 창 속 요원이 감전되고 있었다 |

## 처음 검사가 틀렸던 이유
- 신화 검사는 처음에 불러오기 분기를 검사 안에 다시 적었다.
- 그래서 게임 코드가 틀려도 검사는 통과했다.
- 실제 코드 경로를 거치지 않는 검사는 통과해도 믿을 수 없다.

## 확률을 바꾸지 않은 사례
- 10-21에 전투방에서 사이버웨어가 잘 안 나온다는 보고가 들어왔다.
- 실제 보상 추첨 코드로 20방을 돌려 보니 보상 칸 40개 중 21개가 사이버웨어였다.
- 그래서 확률은 바꾸지 않았다.
