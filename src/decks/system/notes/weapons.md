> 무기 슬롯은 근접과 총 두 개이고, 무기를 고르는 기준은 좌클릭보다 우클릭 고유 능력입니다.

## 우클릭 자원 !wide
| 무기 | 우클릭 | 자원 |
|---|---|---|
| 카타나 | 발도 | 횟수 + 재사용 |
| 해머 | 투척 (우클릭으로 준비, 좌클릭으로 던짐) | 재사용 4초 |
| 나이프 | 투척, 배후 일격 | 재사용 1.5초, 처치하면 즉시 초기화 |
| 체인소드 | 갈아넣기 | 재사용 |
| 피스톨 | 수류탄 | 2회, 7초마다 1회 충전 |
| SMG | 액티브 리로드 | 재사용 |
| 샷건 | 초크 사격 | 없음 |
| 스나이퍼 | 조준 사격 (우클릭으로 준비, 좌클릭으로 발사) | 재사용 |

## 우클릭을 배우는 순서 !wide
::: flow
- 튜토리얼 2단계 | 카타나 발도로 우클릭을 처음 쓴다
- 수류탄 | 피스톨로 바꿔 적 무리를 처리한다
- 설명 창 | 게이지 이미지로 충전과 횟수를 설명한다
:::
- 직접 써 본 뒤에 설명 창을 띄워서, 게이지가 무엇을 뜻하는지 바로 연결되게 한다.

## 무기를 하나씩 해금하는 의도
- 첫 판에 여덟 종을 모두 주면 무기 간 차이를 배우기 전에 골라야 한다.
- 기본 무기인 카타나와 피스톨로 조작을 먼저 익힌다.
- 해금한 무기는 죽어도 유지된다.

## 무기 슬롯 밖의 공격
- 고릴라 암즈와 투사체 발사기는 팔 사이버웨어라서 무기 슬롯을 차지하지 않는다.
- 3번 키로 쓰고, 팔 슬롯을 늘리면 4번 키도 쓸 수 있다.
- 맨손은 해머를 던졌을 때와 튜토리얼 1단계에만 있고, 직접 고를 수 없다.
