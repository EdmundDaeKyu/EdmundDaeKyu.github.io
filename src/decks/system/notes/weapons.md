> 무기 슬롯은 근접과 총 두 개입니다. 무기 선택 기준은 좌클릭보다 우클릭 고유 능력입니다.

## 우클릭 자원 !wide
| 무기 | 우클릭 | 자원 |
|---|---|---|
| 카타나 | 발도 | 횟수 + 재사용 |
| 해머 | 투척 (우클릭으로 준비, 좌클릭으로 던짐) | 재사용 4초 |
| 나이프 | 투척, 배후 일격 | 재사용 1.5초, 처치하면 즉시 초기화 |
| 체인소드 | 갈아넣기 | 재사용 |
| 피스톨 | 수류탄 | 2회, 7초마다 1회 충전 |
| SMG | 액티브 리로드 | 재사용 |
| 샷건 | 초크 사격 | 없음 |
| 스나이퍼 | 조준 사격 (우클릭으로 준비, 좌클릭으로 발사) | 재사용 |

## 우클릭 학습 순서 !wide
::: flow
- 튜토리얼 2단계 | 카타나 발도로 우클릭 첫 사용
- 수류탄 | 피스톨로 바꿔 적 무리 처리
- 설명 창 | 게이지 이미지로 충전과 횟수 설명
:::
- 직접 사용한 뒤 설명 창을 띄웁니다. 게이지의 의미를 사용 경험과 바로 연결하는 것이 목적입니다.

## 무기 순차 해금 의도
- 첫 판에 여덟 종을 모두 주면 무기 간 차이를 배우기 전에 선택해야 합니다.
- 기본 무기 카타나와 피스톨로 조작을 먼저 익힙니다.
- 해금한 무기는 사망 후에도 유지됩니다.

## 무기 슬롯 외 공격
- 고릴라 암즈와 투사체 발사기는 팔 사이버웨어입니다. 무기 슬롯을 차지하지 않습니다.
- 3번 키로 사용하고, 팔 슬롯을 늘리면 4번 키도 사용할 수 있습니다.
- 맨손은 해머를 던졌을 때와 튜토리얼 1단계에만 있고, 직접 선택할 수 없습니다.
