> 부위 이름만으로 바뀌는 효과를 알 수 있도록 부위마다 담당 영역을 하나로 정합니다.

## 담당 영역과 방 선택 !wide
::: flow
- 문에 부위 표시 | 연구실, 전투방, 엘리트방 문에 보상 부위 표기
- 빈 슬롯 확인 | 예: 팔 슬롯 비어 있음
- 경로 선택 | "연구실 · 팔" 문을 고를 이유 발생
:::

## 슬롯 확장
::: stats
- 1500 | 팔, 다리, 신경계, 골격, 순환계, 외피 슬롯 +1
- 3000 | OS 보조 코어 (Q 키)
:::
- 눈은 기본 2슬롯으로 고정됩니다.
- 팔과 OS 슬롯은 조작 키(3·4번, E·Q)와 바로 연결됩니다. 따라서 작업대 영구 강화로만 늘립니다.
- 리퍼닥에서는 슬롯을 확장할 수 없습니다.

## 좌대 규칙
- 같은 계열의 하위와 상위 사이버웨어(고릴라 암즈와 킹콩 암즈)는 한 좌대에 함께 나오지 않습니다.
- 함께 나오면 선택이 더 좋은 쪽 고르기로 끝나기 때문입니다.
- 일반판 장착 후에는 해당 프로토타입을 "올리기"로 제시합니다.
- 모든 부위를 채우고 최대 레벨까지 올리면 교체용 사이버웨어가 나옵니다.

## 사이버웨어 외 보상
- 스탯 보상(공격력, 체력, 이동 속도 등)은 사이버웨어와 별개입니다.
- 스탯 보상은 전투방 보상의 약 30%를 차지합니다.
- 눈 사이버웨어가 없으면 공격 범위(주황)가 보이지 않습니다. 이 경우 예비동작을 보고 회피해야 합니다.
