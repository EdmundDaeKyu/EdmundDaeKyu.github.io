> 빌드 구성과 성장에 쓰이는 시스템의 규칙과 수치를 정리한 세부 기획서.

## 다루는 시스템 !wide
::: cards
- 무기 | 근접 4종, 총 4종, 우클릭 고유 능력
- 사이버웨어 | 8부위, 일반 32종, 프로토타입 9종, 해킹 모드
- 성장 | 경험치와 레벨, 명상, 숙련도
- 경제 | 코인, 작업대, 카드, 회차
:::

## 시스템별 핵심 선택
| 시스템 | 플레이어가 고민할 선택 |
|---|---|
| 무기 | 접근 또는 거리 유지 |
| 사이버웨어 | 빌드 방향 |
| 카드 | 무기 강화 방향 |
| 성장 | 판 종료 후 남는 것 |
| 경제 | 구매 우선순위 |
| 회차 | 보스 처치 후 계속 여부 |

## 기준
- 두 시스템의 선택이 겹치면 하나만 남김.
- 수치 기준은 시스템 기획서와 사이버웨어 레벨 표임.
- 이동 속도, 피해 기준 등 전투 수치는 전투 규칙 기획서에 있음.
