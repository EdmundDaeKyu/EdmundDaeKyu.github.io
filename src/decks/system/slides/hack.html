왼쪽 이미지: 적(쇼트 서킷), 드럼통(유인), 전기 발판(방전)에 동시에 해킹을 업로드하는 장면. 해킹 모드는 E로 켜고 끔. 해킹 모드 중에는 적과 플레이어 모두 0.35배로 느려짐. 좌우 클릭은 무기 공격 대신 해킹으로 바뀜. 해킹은 RAM을 소모하고 1초 업로드 후 적용됨. RAM 최대치는 100이고, 16초면 가득 참. 처치할 때마다 RAM 8 회복. 숙련도 단계마다 최대 RAM +10. 과열은 불 피해 25와 함께 점화 폭발(대상 33, 2m 안 21)을 일으킴. 사이버덱 Lv2(RAM 압축)는 해킹 비용 −25%, Lv3(오버클럭)는 해킹으로 입히는 모든 피해 +50%. 해킹 보조 사이버웨어는 표적 연결 광학(눈), OS 보조(신경계), 눈에는 눈(외피) 3종임. OS 보조와 눈에는 눈은 마비와 OS 게이지라는 공용 규칙에 연결됨. 따라서 사이버덱 없이 전기 무기나 산데비스탄 빌드에서도 사용 가치가 있음. 표적 연결 광학은 해킹 전용임. Lv2의 속성 피해 +25%만 해킹이 아닌 속성 피해에도 적용됨.
