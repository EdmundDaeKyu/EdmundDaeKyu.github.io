> 부위마다 역할을 하나로 정해 부위 이름만으로 효과를 알 수 있게 함.

## 부위별 역할 !wide
| 부위 (기본 슬롯) | 역할 | 대표 사이버웨어 |
|---|---|---|
| 팔 (1) | 3번 키 능력 | 고릴라 암즈, 투사체 발사기, 스마트링크 |
| 다리 (2) | 대시 성능과 효과 | 반사 신경 각부, 젠킨스의 힘줄 |
| 신경계 (2) | 쿨타임, 대시 횟수 | 케렌지코프, 시냅스 버너 |
| 골격 (2) | 내구력 | 본 레이스, 티타늄 골격 |
| 눈 (2) | 정보 (예고 범위, 적 체력, 약점) | 키로시 광학, 표적 분석기 |
| OS (1) | E 특수능력 | 산데비스탄, 사이버덱, 버서크 |
| 순환계 (1) | 회복 | 힐온킬, 아드레날린 부스터 |
| 외피 (2) | 피격 대응 | 강화 피부, 눈에는 눈 |

## 역할을 하나로 정한 근거
- 문에 "연구실 · 팔"이 표시되면 팔 슬롯이 빈 플레이어에게 그 방을 고를 이유가 생김.
- 방 선택과 빌드 구성이 연결됨.

## 레벨과 프로토타입
- 같은 사이버웨어 재획득 시 Lv2, Lv3로 상승. 레벨마다 새 기능 추가.
- 프로토타입은 ??? 방에서만 등장하며 대가(단점)가 있음.
- 숙련도 단계 상승마다 대가 1/3 감소.

## 슬롯 확장
- 눈을 제외한 일곱 부위는 작업대에서 슬롯을 1개씩 확장 가능.
- 비용: OS 3000코인, 나머지 부위 1500코인.
