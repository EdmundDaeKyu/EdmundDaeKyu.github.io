04 예고 표시

실제 판정 범위와 동일한 예고 표시

범위: 실제 도달 거리 기준

전방 2.3m, 70° (점선은 내딛기 1.2m)

표시가 실제보다 넓으면 플레이어가 안전 지점을 위험 지점으로 잘못 학습함.
돌진 거리는 적의 접근 동작으로 판단 가능하므로 표시 범위에서 제외함.

알파: 다중 겹침 기준

예고 한 개

다섯 개 겹침

예고 표시 알파 값 0.16.
단일 예고 기준으로 값을 정하면 적 다섯에게 포위될 때 화면 전체가 주황색으로 덮임.

EDGERUNNERS 전투 규칙 기획서

05

근접병은 실제 도달 거리만큼 전방 부채꼴을 그림. 범위는 내딛기 1.2m와 칼 반경 1.1m의 합인 약 2.3m, 각도는 70°임. 예고 표시 알파 값 0.16은 여러 예고가 겹치는 상황을 기준으로 정함. 발광은 겹칠수록 알파보다 빠르게 밝아지므로 발광 세기도 함께 낮춤. 오른쪽 두 그림은 같은 부채꼴을 알파 0.16으로 한 개, 다섯 개 겹쳐 그린 도해이며 게임 화면이 아님. 바닥 장치도 색만으로는 바닥 장식과 구분되지 않으므로 형태로 구분함. 전기 함정에만 구리 배선이 박힌 금속 타일을 사용함. 타일 위 색은 무늬가 가려지지 않는 수준(a=0.58)으로 제한함.
