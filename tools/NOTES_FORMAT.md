# 슬라이드 설명 형식

사이트에서 슬라이드마다 아래에 붙는 설명은 `src/decks/<덱>/notes/<슬라이드 id>.md`에 쓴다.
`tools/build_decks.pl`이 이 파일을 칸으로 나눈 설명으로 바꾼다.
파일이 없으면 슬라이드의 `<aside>`(발표자 노트)를 한 문단으로 보여 준다.

## 쓰는 법

```
> 이 장의 핵심을 한 문장으로 적는다.

## 첫 번째 칸의 제목
### 소제목
- 항목 한 줄에 사실 하나
- 항목

## 두 번째 칸의 제목
일반 문장은 한 줄이 한 문단이 된다.

| 항목 | 값 |
|---|---|
| 이동 속도 | 5.0 |

## 전체 폭 칸 !wide
::: flow
- 단계 이름 | 짧은 설명
- 다음 단계 | 짧은 설명
:::
```

| 줄 | 결과 |
|---|---|
| `> 문장` | 칸 위의 핵심 문장 (첫 `##` 앞에 둔다) |
| `## 제목` | 새 칸. 칸은 자동으로 2~3열로 놓인다 |
| `## 제목 !wide` | 한 줄 전체를 쓰는 칸 |
| `### 소제목` | 칸 안의 소제목 |
| `- 항목`, `1. 항목` | 목록 |
| `\| 표 \|` | 표 (둘째 줄 `\|---\|`는 구분선) |
| 그 밖의 줄 | 문단 |
| `` `코드` ``, `**굵게**`, `[글](주소)` | 줄 안 표시 |

## 도식 블록

`::: 종류`로 열고 `:::`로 닫는다.
안에는 `- 제목 | 설명` 항목만 쓴다(`| 설명`은 빼도 된다).

| 종류 | 모양 | 쓰는 곳 |
|---|---|---|
| `flow` | 화살표로 이은 단계 상자 | 순서, 흐름, 한 판의 진행 |
| `cards` | 같은 크기의 상자 여러 개 | 종류 나열, 비교 |
| `stats` | 큰 숫자와 설명 | 핵심 수치 |
| `svg` | 안에 쓴 `<svg>`를 그대로 넣는다 | 위 셋으로 안 되는 도식 |

`svg` 블록은 `viewBox`를 주고 `width`/`height`는 빼서 칸 폭에 맞춘다.
색은 `currentColor`나 사이트 색(`#17181C`, `#5B606B`, `#0077A3`, `#C2185B`, `#D9D7CF`)을 쓴다.

## 내용 기준

- 슬라이드에 이미 적힌 문장을 그대로 다시 쓰지 않는다. 슬라이드가 보여 주는 것의 이유, 수치, 예외를 보탠다.
- 한 칸에는 한 주제만 둔다. 칸은 두 개에서 네 개가 적당하다.
- 항목 한 줄에는 사실 하나를 쓴다. 문단은 두 문장을 넘기지 않는다.
- 표현은 게임 기획서에서 흔히 쓰는 평범한 말로 쓴다. 기준은 Edgerunners 저장소의 용어 · 표현 기준을 따른다.
