Edgerunners

사이버펑크 2077을 탑다운 로그라이트로 재구성한 게임.
빌드 구성 → 빌드 시험 → 적 웨이브 처치의 반복 구조.

장르
탑다운 액션 로그라이트
플랫폼
PC, 웹 브라우저
엔진
Godot 4.7.2
한 판
방 12개를 지나 보스까지

플레이하기

PC, 키보드 · 마우스 조작. 웹 판은 크롬 · 엣지에서 실행.

웹 판 첫 로딩 1분 이상 소요(재실행 시 약 15초).
대기 없이 실행하려면 Windows 판 압축 해제 후 Edgerunners.exe 실행.

웹에서 플레이 Windows 판 내려받기 · 116MB

핵심 재미

빌드 구성, 빌드 시험, 적 웨이브 처치.

빌드 구성

사이버웨어 8부위 32종, 프로토타입 9종, 무기 8종 조합.
같은 사이버웨어 재획득 시 최대 Lv3까지 상승. 레벨마다 새 기능 추가.

빌드 시험

문에 표시된 보상을 보고 다음 방 선택.
방마다 적 조합 · 장치가 다름. 같은 빌드도 매번 다른 상황에서 시험됨.

적 웨이브 처치

웨이브당 적 7~9명.
모든 적 공격에 예고 표시. 예고를 보고 회피 가능. 빌드 조합이 맞으면 다수 적 동시 처치.

2077과 다르게 쓴 무기와 사이버웨어

이름은 사이버펑크 2077 원작을 따름. 사용 방식은 탑다운 전투에 맞게 변경함.

OS · E키

산데비스탄

2077: 일정 시간 주변 시간 감속, 사용자만 정상 속도로 이동.

켜고 끌 수 있는 감속과 공격력 +25%.
적 처치 시마다 지속 시간 +0.4초(Lv2).

OS · E키

사이버덱

2077: 적 스캔 후 퀵핵으로 방해 또는 피해.

해킹 모드 중 적 · 플레이어 모두 0.35배 감속.
좌 · 우클릭으로 적, 드럼통, 전기 발판 해킹.

팔 · 3번 키

고릴라 암즈

2077: 주먹 근접 무기.

무기 슬롯과 별도인 능력. 적 잡아 던지기 · 내려찍기.
던진 적과 충돌한 적도 넘어짐(Lv2).

카타나 · 해머 · 나이프

근접 무기

2077: 베기 · 내려치기 무기.

무기별 우클릭 고유 능력 1개.
카타나: 관통 베기. 해머: 투척 후 회수. 나이프: 꽂힌 적 뒤로 순간이동 후 찌르기.

장면

게임 내 촬영 장면. 클릭 시 확대.

한 판의 흐름

시설 출격 → 방 12개 → 보스전.

튜토리얼첫 판 한정. 숲속 맵 3개에서 기본 조작 교습
시설 입장방무기 해금, 작업대 강화, 명상
방 12개 (갈림길)문마다 방 종류 · 보상 표시
휴식방보스 앞에서 회복과 정비
보스기업 히트맨, 2페이즈
보스 처치 시 다음 회차업그레이드 · 카드 · 코인 유지 후 다음 회차 진입. 회차마다 적 체력 +50%, 피해 +30%.
사망 시 시설로 복귀장착 사이버웨어 상실. 코인, 레벨, 명상 스킬, 작업대 강화, 무기 해금 유지.
